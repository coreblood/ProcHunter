# ProcHunter

Uncapped Vault proc scanner for WoW 3.3.5a (private server "Uncapped").

Lists every vault item that is equippable by anyone and carries a proc, matched against a bundled item→proc database. Read-only: the only wire message it sends is `VLTGET`.

`/ph` to open. See the release assets for the Guide and nutshell PDFs.
